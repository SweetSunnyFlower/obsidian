1. Knowledge map

5. Core workflow
6. Command reference

10. End-to-end example

## Selection rule

Start with 6–12 notes. Merge notes that would be shorter than a few screens or that cannot stand alone. Split a note only when it has a distinct mental model and a clear inbound link.
