# 什么是栈

栈只有一个原则：

> 后进先出（LIFO）

英文：

```text
Last In First Out
```

---

## 现实例子

想象一摞盘子：

```text
    5
    4
    3
    2
    1
```

你只能：

```text
从顶部放
从顶部拿
```

不能：

```text
拿中间那个3
```

---

## 栈的两个操作

### Push（入栈）

```text
栈：

3
2
1
```

Push(4)

变成：

```text
4
3
2
1
```

---

### Pop（出栈）

```text
4
3
2
1
```

Pop()

得到：

```text
4
```

剩下：

```text
3
2
1
```

---

# Go实现栈

Go没有内置Stack。

通常用Slice实现：

```go
type Stack []int

func (s *Stack) Push(v int) {
    *s = append(*s, v)
}

func (s *Stack) Pop() int {
    n := len(*s)

    v := (*s)[n-1]

    *s = (*s)[:n-1]

    return v
}
```

# 为什么函数调用会形成栈

这是最重要的部分。

看：

```go
func A() {
    B()
}

func B() {
    C()
}

func C() {
}
```

执行：

```go
A()
```

---

CPU需要记住：

```text
A执行到哪里
B执行到哪里
```

所以形成：

```text
C
B
A
```

---

执行完C：

```text
弹出C
```

回到：

```text
B
A
```

---

执行完B：

```text
弹出B
```

回到：

```text
A
```

---

这就是：

```text
调用栈（Call Stack）
```

---

# 为什么递归会栈溢出

例如：

```go
func Test() {
    Test()
}
```

执行：

```text
Test
Test
Test
Test
Test
...
```

不停压栈：

```text
┌─────┐
│Test │
├─────┤
│Test │
├─────┤
│Test │
├─────┤
│Test │
├─────┤
│Test │
└─────┘
```

最终：

```text
Stack Overflow
```

# 什么是队列

队列原则：

> 先进先出（FIFO）

英文：

```text
First In First Out
```

---

## 现实例子

银行排队：

```text
张三
李四
王五
赵六
```

---

张三先来：

```text
先办理
```

---

赵六最后来：

```text
最后办理
```

# Queue操作

## Enqueue

入队：

```text
1 2 3
```

加入：

```text
4
```

变：

```text
1 2 3 4
```

---

## Dequeue

出队：

```text
1 2 3 4
```

取出：

```text
1
```

剩：

```text
2 3 4
```

---

# Go实现队列

简单版：

```go
type Queue []int

func (q *Queue) Push(v int) {
    *q = append(*q, v)
}

func (q *Queue) Pop() int {
    v := (*q)[0]

    *q = (*q)[1:]

    return v
}
```

---

# 栈和队列对比

| | 栈 | 队列 |
|------|------|------|
| 英文 | Stack | Queue |
| 原则 | 后进先出 | 先进先出 |
| Push | 顶部 | 尾部 |
| Pop | 顶部 | 头部 |

# Go Channel其实也是队列

例如：

```go

ch <- 1
```





