# 第一课：网络到底是什么？

很多人觉得：

```text
网络 = WiFi
```

或者：

```text
网络 = Internet
```

其实都不是。

一句话：

> **网络就是让两台计算机能够交换数据。**

就是这么简单。

---

## 我们先不要谈互联网

假设：

你有两台电脑。

```text
电脑A

电脑B
```

如果：

用一根网线连接。

是不是已经可以传文件？

可以。

那么：

这就是：

```text
网络
```

注意：

这里：

```text
没有：

百度

腾讯

阿里

Google
```

只有：

两台电脑。

---

## 网络最核心的问题

如果：

电脑A：

发送：

```text
Hello
```

电脑B：

怎么知道：

这是：

```text
Hello
```

而不是：

```text
Hell
```

或者：

```text
ello
```

？

所以：

网络需要解决：

第一件事：

```text
数据怎么传？
```

---

## 第二个问题

如果：

世界：

只有：

两台电脑。

简单。

但是：

如果：

变成：

```text
1000000台
```

怎么办？

电脑A：

如何找到：

电脑B？

于是：

需要：

```text
地址
```

这就是：

以后：

IP地址。

---

## 第三个问题

如果：

大家：

同时：

发消息。

例如：

```text
A -> B

C -> B

D -> B

E -> B
```

怎么办？

总不能：

混在一起。

于是：

需要：

```text
协议
```

规定：

格式。

---

所以：

计算机网络：

其实：

一直：

围绕：

三个问题。

```text
怎么传？

↓

传给谁？

↓

怎么保证不乱？
```

整个：

TCP/IP。

其实：

都是：

围绕：

这三个问题。

# 网络其实不关心你的数据

很多初学者：

误以为：

网络：

知道：

```text
图片

视频

Word

Excel
```

不是。

网络：

只认识：

```text
010101010
```

比特流。

例如：

图片：

```text
JPEG
```

最终：

也是：

```text
010101
```

视频：

```text
MP4
```

也是：

```text
010101
```

Go：

发送：

```go
conn.Write([]byte("Hello"))
```

最后：

也是：

```text
48 65 6C 6C 6F
```

```text

↓

↓

```

程序员：

疯了。

于是：

网络：

采用：

```text
分层
```

思想。

每层：

只做：

自己的事情。

以后：

你会看到：

```text
HTTP

TCP

IP

MAC
```

其实：

就是：

不同层。

# 网络真正传输的是什么？

很多人觉得：

发送：

```go
conn.Write([]byte("Hello"))
```

网络：

发送：

```text
Hello
```

不是。

真正：

发送：

的是：

```text
Packet（数据包）
```

例如：

```text
┌────────────────────┐
│ Header             │
├────────────────────┤
│ Hello              │
└────────────────────┘
```

Header：

里面：

有：

```text
源地址

目标地址

长度

协议

校验
```

真正：

的数据：

只有：

```text
Hello
```

以后：

我们：

讲：

TCP。

HTTP。

IP。

其实：

都是：

不停：

往：

Header：

里面：

增加：

信息。
