# 什么是堆

堆本质是一棵特殊的树。

例如：

```text
        1
      /   \
     3     5
    / \   / \
   8  10 6  9
```

这是一棵：

```text
最小堆（Min Heap）
```

---

规则：

```text
父节点 <= 子节点
```

---

例如：

```text
1 <= 3
1 <= 5

3 <= 8
3 <= 10

5 <= 6
5 <= 9
```

成立。

---

# 最大堆

反过来：

```text
        100
      /     \
     80      70
    / \     / \
   40 30   20 10
```

规则：

```text
父节点 >= 子节点
```

---

这叫：

```text
最大堆（Max Heap）
```

---

# 堆和二叉搜索树的区别

很多人搞混。

---

BST：

```text
       50
      /  \
    30    80
```

规则：

```text
左边都小
右边都大
```

---

Heap：

```text
       50
      /  \
    80    60
```

居然也是合法的。

因为：

```text
50 <= 80
50 <= 60
```

满足最小堆。

---

所以：

### BST保证顺序

```text
左小右大
```

---

### Heap只保证父子关系

```text
父亲最小
```

或者：

```text
父亲最大
```

---

# 为什么需要堆

假设：

```text
100
3
50
7
9
1
20
```

---

现在要不断找：

```text
最小值
```

---

数组方案：

```go
arr := []int{
    100,3,50,7,9,1,20,
}
```

找最小值：

```go
min := arr[0]

for _, v := range arr {
    if v < min {
        min = v
    }
}
```

---

复杂度：

```text
O(n)
```

---

数据：

```text
100万
```

呢？

每次：

```text
扫描100万次
```

---

太慢。

---

# 堆的优势

最小堆：

```text
        1
      /   \
     3     5
```

规则保证：

```text
根节点一定最小
```

---

取最小值：

```text
直接拿根节点
```

复杂度：

```text
O(1)
```

---

这就是堆存在的意义。

---

# 堆怎么插入

原来：

```text
        1
      /   \
     3     5
```

插入：

```text
2
```

---

先放最后：

```text
        1
      /   \
     3     5
    /
   2
```

---

发现：

```text
2 < 3
```

违反规则。

---

交换：

```text
        1
      /   \
     2     5
    /
   3
```

---

这个过程叫：

```text
Heapify Up
上浮
```

---

# 删除最小值

例如：

```text
        1
      /   \
     2     5
    / \
   3   4
```

---

删除：

```text
1
```

---

最后一个元素顶上来：

```text
        4
      /   \
     2     5
    /
   3
```

---

发现：

```text
4 > 2
```

违反规则。

---

交换：

```text
        2
      /   \
     4     5
    /
   3
```

---

继续：

```text
4 > 3
```

交换：

```text
        2
      /   \
     3     5
    /
   4
```

---

完成。

---

这个过程叫：

```text
Heapify Down
下沉
```

---

# 时间复杂度

插入：

```text
O(log n)
```

---

删除：

```text
O(log n)
```

---

获取最小值：

```text
O(1)
```

---

记住：

| 操作 | 时间复杂度 |
|--------|--------|
| 查询最小值 | O(1) |
| 插入 | O(log n) |
| 删除 | O(log n) |

# 为什么堆用数组实现

这里是面试高频。

很多人以为：

```text
Heap
=
树
```

---

实际上：

```text
Heap
=
数组
```

实现。

---

例如：

```text
        1
      /   \
     2     5
    / \   /
   3  4  6
```

存成：

```text
[1,2,5,3,4,6]
```

---

规律：

对于索引 i

左孩子：

```text
2*i + 1
```

---

右孩子：

```text
2*i + 2
```

---

父节点：

```text
(i-1)/2
```

---

所以：

```text
根本不用指针
```

---

CPU缓存友好。

---

获得。

```text
Go Timer

```
